### 1. **Color-Coding: Memory vs. Mental Load**
   - **Memory Reinforcement:** Color-coding primarily aids memory by creating visual anchors. For example, blue for "work documents" or green for "personal files" leverages the brain's strength in processing color faster than text.
   - **Mental Load Reduction:** It streamlines task-switching by eliminating the need to mentally categorize items. A glance at the color tells you the category instantly, freeing up cognitive resources.
   - **Key Tip:** Use 2-3 colors max per category (e.g., red = urgent, blue = projects, green = reference). Too many colors can overwhelm, not simplify.

### 2. **Switching Background Sounds: Science & Personal Preference**
   - **Optimal Timing:** Switching every **60-90 minutes** can refresh attention without disrupting focus. For example:
     - **Lo-fi:** Ideal for deep work (steady beats reduce distraction).
     - **Nature sounds (rain/ocean):** Great for transitions or when fatigued.
   - **Consistency vs. Variety:** If switching feels disruptive, stick to one type (e.g., ambient only). If boredom creeps in, rotate intentionally. Experiment to see what *your* brain prefers.
