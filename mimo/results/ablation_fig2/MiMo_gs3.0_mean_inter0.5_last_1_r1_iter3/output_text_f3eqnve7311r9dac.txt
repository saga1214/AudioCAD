Yes, older comics from the 1940s and 50s are generally much rarer.

Here are ten significant titles from that era that could be considered investments, although they will be expensive.

Number one is *Action Comics* number one again, Superman's debut from 1938.
Number two, *Detective Comics* number twenty-seven, which is Batman's first appearance.
Number three, *Amazing Fantasy* number fifteen from 1939, where Spider-Man first appeared.
Number four, *Marvel Super-Heroes* number one, the first comic with the Fantastic Four.
Number five, *Adventure Comics* number two hundred twenty-eight, which is Superman's first full appearance in color.
Number six is *The Amazing Spider-Man* number fifty, which is the first appearance of the Sinister Six.
Number seven, *Fantastic Four* number forty-eight, which is the first appearance of Galactus.
Number eight, *The Defenders* number one, Luke Cage's first official team-up comic.
Number nine, *Tales to Astonish* number forty-five, the first appearance of Ant-Man.
And finally, number ten is *The Incredible Hulk* number one, where the Hulk first appeared.
