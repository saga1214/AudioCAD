Sure, here’s a quick checklist for when you’re filming yourself. 

1. Ask permission from the venue, especially older audiences like nursing homes assist living.  
2. Set up your phone or camera in a way that captures the puppets clearly.  
3. Make sure the audio is good, so kids’ reactions are heard.  
4. Do a quick test run to make sure everything’s working.  
5. After filming, check the footage to see if it’s usable.  

That’s the basic answer. Good luck with the show!
