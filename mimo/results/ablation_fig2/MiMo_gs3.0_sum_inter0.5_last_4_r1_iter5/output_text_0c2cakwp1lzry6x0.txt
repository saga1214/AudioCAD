Here's a step-by-step guide for each installation, keeping your rules and new routines in mind:

### 1. **TV Mount Installation**
   - **Prep:** Confirm wall type (drywall/concrete) using a stud finder. Check mount weight limits vs. TV specs.
   - **Tools:** Power drill, level, measuring tape, pencil.
   - **Steps:**
     1. Mark screw holes on wall per mount instructions.
     2. Drill pilot holes (size matches screws). For drywall, use plastic anchors if no studs.
     3. Secure mount to wall. Tighten screws gently—don’t overtighten.
     4. Hang TV and adjust for level.
   - **Safety:** Wear safety glasses. If drilling late, ensure landlord rules are followed (e.g., no noise after 10 PM).

### 2. **Hanging Planters**
   - **Prep:** Choose sturdy hooks/brackets. Place heavier pots lower for balance.
   - **Tools:** Drill, screwdriver, measuring tape.
   - **Steps:**
     1. Mark hook locations (e.g., near windows for light).
     2. Drill pilot holes into studs or use anchors in drywall.
     3. Secure hooks. Test weight capacity.
     4. Hang planters. Use decorative hooks for style.
   - **Tip:** Install Sunday morning to avoid stiffness and noise complaints.

### 3. **Floating Shelves**
   - **Prep:** Measure shelf spans. Check wall studs (critical for heavy items).
   - **Tools:** Drill, level, shims (for uneven walls).
   - **Steps:**
     1. Mark shelf positions. Space shelves 12–18" apart for stability.
     2. Drill into studs at both ends. Use anchors if needed.
     3. Insert shelf brackets, tighten screws, and level.
     4. Place heavier items (e.g., vases) at the bottom.
   - **Safety:** Use a step stool. Double-check levels.

### General Tips:
- **Drill Smartly:** Use a stud finder with drill mode. Keep noise minimal late evenings.
- **Time Management:** Dedicate Sunday afternoons (9 AM–4 PM) for installations. Pair with your 5-minute stretches hourly!
- **Decorate Strategically:** Install decor *outside* your workspace first. Use masking tape to test placement before drilling.
- **Safety First:** Always wear safety glasses. Test installations before relying on them.

**Key Takeaway:** Break tasks into 30-minute sessions. Install one item at a time to avoid distraction fatigue. Celebrate small wins—it’s your new space! 🛠️✨
