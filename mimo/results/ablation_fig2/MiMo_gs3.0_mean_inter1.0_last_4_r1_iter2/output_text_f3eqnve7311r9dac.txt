You're right, older comics are generally rarer, but they can be very fragile and expensive to get in good condition. Here are ten iconic titles from the 1940s and 50s that are historically important and can be found in the under-five-hundred-dollar range for a decent copy.

First, *Action Comics* number four, which re-introduced Superman.
Second, *Detective Comics* number twenty-seven, which is Batman's first appearance.
Third, *Amazing Comics* number four, featuring the first cover of the Flash.
Fourth, *Warrior* number three, the first comic cover to feature Captain America.
Fifth, *The Human Torch* number one, which introduced the Fantastic Four.
Sixth, *Tales to Astonish* number one, featuring the first appearance of Ant-Man and the Wasp.
Seventh, *The Avengers* number one, the first comic to feature the entire team.
Eighth, *Fantastic Four* number one, the first appearance of Galactus.
Ninth, *Spectacular Spider-Man* number one, which features the first appearance of the Sinister Six.
And tenth, *Daredevil* number one, which is the first appearance of Elektra.
