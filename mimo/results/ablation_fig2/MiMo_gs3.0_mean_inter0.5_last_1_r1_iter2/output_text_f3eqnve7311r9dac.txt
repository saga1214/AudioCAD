That's a very smart thought. Older comics from the forties and fifties are much rarer and generally more valuable.

Here are ten significant books from that era. Just keep in mind that most will cost more than five hundred dollars, and many will be well over five thousand. The condition is absolutely critical for any valuable book.

Number one: *Action Comics* number one again, Superman's first full appearance.
Number two: *Detective Comics* number twenty-seven, where Batman makes his debut.
Number three: *Amazing Fantasy* number fifteen, Spider-Man's first.
Number four: *Web of Science* number one, which is the first appearance of Doctor Strange.
Number five: *Tales to Astonish* number forty-five, the first appearance of the Fantastic Four.
Number six: *The Avengers* number one, which features the original team.
Number seven: *Fantastic Four* number forty-eight, where Galactus first appears.
Number eight: *The Incredible Hulk* number one, with the first full appearance of the Hulk.
Number nine: *Captain Marvel* number one, the first appearance of Captain Marvel.
Number ten: *Daredevil* number one, which was the first appearance of the character.

And one last thing, it's very important to remember that condition is everything in the high-end market. You should only buy comics that have been professionally graded.
