### **Color-Coding Icons**  
The benefit is **both memory and reducing mental load**. Color-coding leverages visual cues to:  
- **Speed up recall** (e.g., red for urgent tasks, blue for projects).  
- **Minimize decision fatigue** by instantly categorizing chaos.  
Start with **2–3 colors max**—too many can overwhelm. Test it for a week: if it feels intuitive, keep it!  

### **Switching Background Sounds**  
This is **mostly personal preference**, but timing helps:  
- **Lo-fi** (steady rhythm) → Best for deep work.  
- **Nature sounds** (rain/ocean) → Great for creative breaks.  
→ Try **switching every 45–60 minutes** if you feel restless. If lo-fi keeps you focused, stick with it!  

### **Tackling Physical Documents**  
**Do it on a quieter day!** Breaking tasks into chunks reduces overwhelm. Progress comes from:  
1. **Environment**: A tidy workspace signals "start here."  
2. **Chunking**: Focus on one category (e.g., "invoices") before moving to the next.  
→ **Tip**: Set a 90-minute timer. Stop when the pile is 50% smaller—you’ll feel accomplished!
