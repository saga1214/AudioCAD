### 1. **Color-Coding for Desktop Icons: Memory vs. Mental Load**
   - **Memory Aid**: Color-coding *can* help with recall if you assign consistent colors to consistent categories (e.g., red for "Urgent," blue for "Projects").  
   - **Mental Load**: If overdone (e.g., 10+ colors), it can *increase* cognitive effort. **Best approach**: Use 2-3 primary colors for broad categories (e.g., green = work files, purple = personal), then sub-colors for specificity.  
   *Key takeaway*: Keep it simple—**aim for visual harmony, not chaos**.

### 2. **Switching Background Sounds: Focus or Distraction?**
   - **Lo-Fi/Chill Vibes**: Ideal for sustained focus (steady rhythm, minimal lyrics).  
   - **Nature Sounds**: Great for resetting attention (rain/ocean can trigger calm).  
   - **Optimal Timing**: Try a **30-minute "focus block"** with lo-fi, then switch to nature sounds for 15 minutes to reset. If focus dips, switch genres.  
   *Key takeaway*: **Consistency > Constant Change**. If one vibe works, stick with it for deep work.

### 3. **Tackling Physical Documents: Environment vs. Chunking**
   - **Environment**: A clean workspace *does* reduce decision fatigue, but **chunking tasks** (e.g., "Sort invoices," not "Organize everything") is more impactful.  
   - **Best Strategy**: Dedicate 90-minute blocks on weekends with:  
     - A labeled sorting station (trash/recycle/action).  
     - Progress tracking (e.g., "Solved 3 piles!").  
   *Key takeaway*: **Environment sets the stage; chunking drives momentum**.
