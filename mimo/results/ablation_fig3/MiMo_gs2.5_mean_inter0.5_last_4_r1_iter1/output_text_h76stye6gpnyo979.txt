That pigeon problem is a great way to think about how to organize things!

Just like you'd figure out the pigeon situation, you can create a clear, logical plan.

First, decide which goal feels more urgent—the apartment down or Bolivia/Salt Flats/Ferro Islands.

Then, just like with the pigeons, you'd start by putting one on each rooftop. So, you could create one small savings account for each goal.

Next, set a small, fixed amount you can put into each fund every month, based on your budget.

Finally, you can create a simple to-do list with one tiny action for each goal, like 'research Salt Flats flights' or 'look up down payment savings calculators.'

This method keeps you moving forward on everything without getting overwhelmed.
